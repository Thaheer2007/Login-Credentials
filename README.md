# MECHNIK — Your Vehicle • Our Care

A modern, responsive web application connecting vehicle owners with verified local mechanics and service centers across Cars, Bikes, Trucks, and Tractors.

## Features
- **Vehicle Selection & Filtering**: Search and filter mechanics for Two-Wheelers, Four-Wheelers, Commercial Trucks, and Agricultural Tractors.
- **Smart Location**: Real-time browser GPS geolocation with reverse geocoding & manual locality search.
- **Service Booking Flow**: 4-step booking with vehicle details, service selection, problem description (including voice recording and photo uploads), and doorstep/workshop pickup slots.
- **Interactive Mechanic Portal**: Manage incoming requests, accept jobs, update progress statuses (`Requested` → `Accepted` → `In Progress` → `Completed`), and generate final invoices.
- **Owner Dashboard & History**: Real-time service tracking, complete service history, and star ratings/reviews.
- **Admin Management**: Platform overview, verified mechanic roster, customer bookings, and dispute handling.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- LocalStorage State Persistence (MechnikContext)

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
